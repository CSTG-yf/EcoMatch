# QA-02A 权限与脱敏接口测试

QA-02A 将权限、越权、动态脱敏、缓存隔离、历史访问、业务解释和敏感日志测试聚合成一个可归档的后端安全门禁。

```powershell
python evaluation/run_qa02a.py `
  --output .local-dev/bank-evaluation/qa02a-report.json
```

执行器读取 `evaluation/qa02a_manifest.json`，调用 Maven 执行清单声明的测试类，并解析本次生成的 Surefire XML。以下情况均返回退出码 `1`：

- Maven 执行失败。
- 声明的测试类没有生成本轮报告。
- 任一测试失败或跳过。
- 任一控制项未通过。

清单当前覆盖七类控制项：

1. 身份认证和垂直权限；
2. 水平对象越权；
3. 行列权限；
4. 动态脱敏；
5. 缓存安全隔离；
6. 历史和模型解释泄露；
7. 敏感日志泄露。

执行器错误或清单无效返回退出码 `2`。报告只保存测试类、用例数量、耗时和清洗后的失败摘要，不保存响应数据、SQL、凭据或原始测试输出。
