# QA-02C 全链路安全门禁

QA-02C 将权限、脱敏、审计、告警、导出、分享、历史、模型输入、敏感日志和前端发布产物聚合为一个失败封闭的仓库级门禁。

## 执行

```powershell
python evaluation/run_qa02c.py `
  --output task/QA-02C_REPOSITORY_ACCEPTANCE_REPORT.json
```

执行器按顺序：

1. 重新执行 QA-02A 权限与脱敏门禁。
2. 重新执行 QA-02B 审计与告警门禁。
3. 执行导出、分享、历史、模型输入和日志的跨模块 Java 测试。
4. 执行 FE-06/FE-08 前端安全回归。
5. 构建开源版前端生产产物。

任一命令失败、报告缺失或任务标识不符、Java 测试类未执行、用例失败/跳过、证据未绑定控制项，都会导致 `status=FAIL` 和非零退出码。

## 控制项

- 身份、对象权限、行列权限、动态脱敏和缓存隔离。
- 审计完整性、异常告警、处置状态和机构隔离。
- 导出服务端重查、看板定义一致性、下载身份和审计。
- 分享有效期、撤销、访问上限、查看者身份、脱敏和水印。
- 历史所有权和 Chat/Semantic/SQL 模型输入边界。
- 公共日志、查询日志、导出/分享响应和前端错误状态的敏感数据外泄。
- FE-06/FE-08 客户端回归和生产构建。

## 报告边界

报告只保留控制项、证据状态、用例数、耗时和脱敏失败摘要，不保留原始 SQL、Token、凭据、JDBC URL 或金融数据。

`scope=REPOSITORY` 只证明仓库回归通过。最终发布前必须在正式身份属性、生产权限/脱敏/审计规则和目标部署环境下执行环境门禁。
