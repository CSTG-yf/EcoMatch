## 3. 必须实现的接口能力

- `GET /api/semantic/dashboard`：仅返回当前用户可见看板，支持主题域、状态和分页筛选。
- `GET /api/semantic/dashboard/{id}`：返回详情前执行对象权限校验。
- `POST /api/semantic/dashboard`：创建草稿，服务端写入所有者和审计字段。
- `PUT /api/semantic/dashboard/{id}`：校验版本后更新，不允许修改所有者。
- `POST /api/semantic/dashboard/{id}/copy`：复制为当前用户草稿。
- `POST /api/semantic/dashboard/{id}/publish`：发布可持续刷新的版本。
- `POST /api/semantic/dashboard/{id}/disable`：停用后禁止普通访问和新分享。
- `DELETE /api/semantic/dashboard/{id}`：仅所有者或具备管理权限的用户可删除。

## 4. 安全边界

- 匿名访问、主题域无权限、对象无权限、跨机构访问统一 fail-closed。
- 读取列表时必须在查询层过滤，不允许先返回再由前端隐藏。
- 配置 JSON 使用结构化校验，限制总长度、组件数量、字段长度和嵌套深度。
- 配置中禁止持久化数据库凭据、访问令牌、原始 SQL 密钥或未脱敏结果快照。
- 旧 Canvas 接口必须接入同一服务鉴权，不能形成旁路。
