# FE-01B 响应式与会话收口实现说明

## 1. 完成范围

- PC 与移动端共用完整的历史会话入口，移动端历史列表以全屏覆盖层展示，关闭或选择会话后返回问数主界面。
- 会话列表恢复本地保存且仍属于当前智能助理的会话；失效记录自动回退到最新会话。
- 切换智能助理或会话时清空旧状态，通过请求序号丢弃迟到响应，避免历史消息串入其他会话。
- 历史分页按问题编号去重，加载更早消息后保持原可见位置。
- 会话列表和历史消息均提供加载、空数据、失败与重试状态。
- 收起历史面板后不再保留固定宽度，主问数区域在 PC 和移动端均可完整使用。

## 2. 主要实现

| 模块 | 实现 |
| --- | --- |
| 会话选择 | `conversationState.ts` 校验本地会话编号，并提供稳定回退策略 |
| 历史续问 | 首屏替换、分页前插及问题编号去重 |
| 请求隔离 | 会话列表和消息历史分别使用请求序号忽略迟到响应 |
| 异常恢复 | 列表和消息区域提供错误提示及原页重试 |
| 响应式布局 | 历史面板默认完全收起；移动端打开后覆盖主区域 |
| 移动端能力 | 移动端输入工具栏开放“历史对话”，选择后自动关闭面板 |

## 3. 验证结果

- `conversationState.test.ts`：4 个用例通过。
- `pnpm --filter supersonic-fe build:os`：生产构建通过，包含 PC、移动端和 `/security` 页面产物。
- `pnpm --filter supersonic-chat-sdk build` 仍受仓库既有 Rollup TypeScript 插件配置影响，在 `src/index.tsx` 的 `export type` 处失败；主应用使用 Umi 构建并已通过。
