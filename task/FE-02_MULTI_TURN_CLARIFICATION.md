# FE-02 多轮上下文与澄清交互实现说明

## 1. 完成范围

- 接入 BE-04 的 `multiTurnContext` 正式协议，展示继承轮次、上下文操作、指标、维度、机构、时间和筛选条件。
- 使用最近一个成功轮次作为当前有效上下文，避免把已被后续问题替换的旧条件重新展示。
- 展示 `APPEND`、`REMOVE`、`REPLACE`、`DRILL_DOWN` 和 `RESET` 上下文操作。
- 上下文超过 30 分钟时显示过期提示；摘要被压缩时显示截断提示。
- 支持逐项撤销条件、清空上下文和不参考历史重新解释。
- 接入银行意图接口返回的正式 `clarifications`，支持指标和机构多选、时间及分析方式单选。
- 需要澄清时停止 SQL 解析和执行，用户完成全部选择后再生成明确问题提交。
- 每条历史问题均可一键带入输入框继续提问，不需要重新输入原问题。
- PC 和移动端使用相同能力，澄清项和上下文内容在移动端自动改为单列。

## 2. 协议映射

| 前端能力 | 正式字段 |
| --- | --- |
| 继承轮次与上限 | `multiTurnContext.usedRounds`、`maxRounds` |
| 上下文操作 | `multiTurnContext.operation` |
| 有效上下文 | `multiTurnContext.turns` 的最近成功轮次 |
| 过期与压缩 | `expired`、`truncated` |
| 重写结果 | `rewrittenQuery` |
| 澄清问题及候选 | `BankIntentResult.clarifications` |
| 是否阻断执行 | `BankIntentResult.clarificationRequired` |

## 3. 安全与一致性

- 不在前端构造模拟指标、机构或时间候选，全部使用银行意图接口返回值。
- 撤销、清空和重新解释通过新的自然语言问题进入 BE-04 状态机，不直接篡改服务端上下文。
- 上下文展示不包含 LLM 请求、原始提示词或未脱敏结果数据。

## 4. 验证结果

- Chat SDK：5 个测试套件、17 个用例全部通过。
- 新增测试覆盖有效上下文选择、机构识别、条件撤销、清空、重新解释、单选、多选、澄清完整性、过期状态和历史续问。
- `pnpm --filter supersonic-fe build:os`：生产构建通过，PC 和移动端入口均成功生成。
