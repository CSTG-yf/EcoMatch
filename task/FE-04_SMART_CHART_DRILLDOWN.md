# FE-04 智能图表与下钻实现说明

## 1. 完成范围

- 消费 BE-10 返回的 `recommendedChart`、`candidateCharts` 和推荐理由，服务端推荐优先于前端结构兜底。
- 支持指标卡、表格、折线图、柱状图、饼图和组合图六类可视化。
- 支持候选图表切换、数据视图切换、维度下钻和图表点击联动筛选。
- 下钻和联动筛选复用正式 `queryData` 查询链路，并保留其他已有筛选条件。
- 用户切换图表时调用正式反馈接口，后端完成查询所有权校验并写入 required 审计事件。

## 2. 前端实现

### 2.1 图表推荐模型

`visualizationModel.ts` 统一处理图表类型别名、字段兼容性、权限字段、饼图非负约束和候选图表去重。推荐不可执行时降级到结构匹配图表，表格始终作为可用数据视图。

### 2.2 图表与交互

- 指标卡：单指标聚合结果。
- 表格：完整结果数据视图，排序不再修改原始结果集。
- 折线图：时间或有序维度趋势。
- 柱状图：支持多指标分组展示和分类点击。
- 饼图：支持分类点击和联动筛选。
- 组合图：首指标使用柱状系列，其余指标使用折线系列和双轴。
- 下钻：选择下钻维度后重新查询；失败时回滚交互状态。
- 联动筛选：柱状图或饼图点击后，将分类值映射到正式语义维度并重新查询；可移除筛选条件。
- 请求隔离：查询使用请求序号避免旧请求覆盖新结果。

### 2.3 反馈闭环

图表选择器和数据视图切换调用 `/chat/manage/chartFeedback`，提交查询 ID、推荐图表、实际选择图表和反馈来源。反馈失败不阻断图表浏览，但会给出提示。

## 3. 后端实现

- 新增 `ChartFeedbackReq` 请求协议及参数长度校验。
- 新增图表反馈服务和 REST 接口。
- 服务端只接受六类标准图表和两个固定反馈来源。
- 写入前校验当前用户对查询的访问权限。
- 新增 `CHART_VISUALIZATION_CHANGED` 审计事件。
- 审计元数据仅保留推荐图表、选择图表和反馈来源三个白名单字段。
