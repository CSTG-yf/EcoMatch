# QA-02A 权限与脱敏接口测试实现说明

## 完成范围

- 新增 `evaluation/qa02a_manifest.json`，将安全测试映射到身份与垂直权限、水平越权、行列权限、动态脱敏、缓存隔离、历史及解释泄露、敏感日志七类控制项。
- 新增 `evaluation/run_qa02a.py`，统一执行跨 `auth`、`common`、`headless` 和 `chat` 模块的 Maven 安全测试。
- 执行器只接受本轮生成的 Surefire XML；声明测试类缺失、失败、跳过或 Maven 非零退出均阻断门禁。
- 报告仅保留聚合结果和清洗后的失败摘要，不保存 SQL、结果行、凭据和原始日志。
